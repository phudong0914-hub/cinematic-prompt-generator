# 🎞️ Video Pipeline & Export Skill

Use this skill when developing export formats, bridge relays, or timeline automation.

## Supported Export Bridges
1. **Google Flow & Gemini Slate**: Direct JSON payload relay with scene breakdown and timeline cues.
2. **Remotion Composition**: Generates programmatic React video specs with frame-accurate camera timings.
3. **CapCut / Final Cut Pro XML**: Generates EDL/XML markers with duration and text layer overlays.
4. **NotebookLM & TVC Package**: Multi-shot scripts formatted with hook, body, and call-to-action (CTA).
